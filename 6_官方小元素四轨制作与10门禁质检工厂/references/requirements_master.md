# 越南语字幕与小元素库全量需求总纲 (`requirements_master.md`)

> 本文档完整沉淀管理员对「越南语字幕库 (`vn-subtitle-cloud`)」及所有字幕(`S-*`)、覆层(`O-*`)、动画小元素(`E-*`)的真实业务与技术要求，作为所有生产与审计脚本的唯一准绳。

---

## 一、受众画像与宗教视觉红线（Vietnamese Catholic Bright & Festive Standard）

1. **核心受众**：越南天主教中老年及家庭受众为主，主阵地为 **Facebook Reels (`9:16`) 与信息流 (`4:5`)**。画面必须**明亮、喜庆、圣洁、超大高对比、手机一眼看清**，严禁阴暗压抑、暗黑脏边、蚂蚁小字。
2. **宗教元素绝对红线**：
   - **严禁苦难相（Crucifix）**：十字架一律使用**空十字 / 荣光金十字 / 宝石珍珠花环十字**，绝对禁止带主耶稣受难像（Corpus/Crucifix）的十字架或念珠，也严禁纯黑/深暗色十字架。
   - **严禁耶稣与圣婴人物像**：禁止生成主耶稣形象、圣婴形象、圣母抱圣婴、若望/圣若瑟抱圣婴类小元素。
   - **天使礼仪规范**：祈祷动作的天使**必须闭眼**；全身必须穿端庄白色/金色长袍（严禁出现未穿衣服的裸露感）；双翼须为饱满洁白或金边白羽。
   - **白鸽/圣心扩展**：可用雪白展翅白鸽（含玫瑰/金环/空十字）、燃烧红宝石圣心、圣体显供台、圣爵、百合玫瑰花环、祝福飘带牌匾（`AMEN`、`CHÚA BAN PHƯỚC`、`CẢM ƠN CHÚA` 等）。
3. **100% 原创无版权风险**：所有元素底图与动画必须自生成或程序化绘制，**严禁直接截取他人视频画面当素材**。
4. **预览衬底铁律**：网站与审片拼图**严禁只用纯黑背景掩盖抠图缺陷**！默认强制使用明亮中性实景背景 `stage-photo.jpg`（仅纯白无底框/发光金字字幕或暗夜类可使用 `photo-dark`，深色字或浅奶油贴纸使用 `photo-light`）。

## 二、透明通道动画小元素 (`E-*`) 全量技术与美学要求

1. **封装与参数规格**：
   - 格式：`WebM`（`VP9 + Alpha`，像素格式 `yuva420p`），`-auto-alt-ref 0 -an`。
   - 画布：`512 × 512`，帧率 `24fps`（程序化标准 `72` 帧 = `3.00s`；AI 视频精选片段 `3s ~ 6s`），体积控制 `80KB ~ 1.8MB`（兼顾网盘与云端传输、网页秒开）。
   - FFmpeg 调用规范：**解码透明 WebM 时必须将 `-c:v libvpx-vp9` 置于 `-i <file.webm>` 之前**，否则透明通道直接丢失！
2. **绝对无缝循环与首帧在场铁律**：
   - **第 0 帧即完整主体**：动画从第 0 帧开始主体就必须以正常大小、完整形态存在并处于运动状态！**严禁**“从半截/空画面开始、白鸽从画外飞入、翅膀从圣心里现冒出来、花朵/火焰由无到有慢慢燃起或长大”。
   - **首尾无缝衔接**：循环结束帧回到第 0 帧时必须丝滑无跳变（无位置瞬间归零、无亮度突变闪烁、无元素凭空闪现/消失）。
   - **动效丰满度**：不可过弱（如仅 1% 微抖等于静图）；火焰必须连续燃烧翻卷、羽毛必须有节奏波动、花瓣/粒子必须连续升腾流动、圣光必须有呼吸或扫描。
3. **零越界、防隐蔽内部裁切与高清像素密度铁律**：
   - **生图前原生比例 + 高清留白（废除 `1080×1920 + >=21%` 模糊套）**：方形主体严禁硬塞进 `9:16` 并四周空出 `>=21%` 浪费一半像素！统一使用 **`prep-still --aspect auto`**（`1:1` / `3:4` / `4:3` 原生匹配，左右底紧致留白 **`8%~10%`**、向上展翅/火焰留白 **`12%~13%`**）并投递 **Colab H3 `multi` (`res: 2`)**；若必须走 Flow 720p，留白也控制在 `10%~12%` 并配 `footage: "帧"` 首尾锁图。
   - **全分辨率解码 + 全帧并集包围盒**：视频转透明 WebM 时，全分辨率解码并扫描**全部帧的并集前景范围**（绝不先缩图丢清晰度），居中单步 Lanczos 缩放落入 `512 × 512` 内部的 **`420 × 420` 安全盒 `[46, 466]`**。
   - **防隐蔽内部平切（`E-074` 教训）**：即便最终画布四周留出了 `46px` 黑/透明边，若原视频生成阶段翅膀/花瓣/光线曾触碰并被原画边界切平，缩进 `512×512` 后依然会在 `y=46` 或 `x=46` 处出现**一条笔直的刀切平边**！必须使用 `G06_INTERNAL_FLAT_CLIP` 逐帧检测极值坐标处的锐利直线阶跃。
4. **亮底无杂边抠像标准（`stage-photo.jpg` 过检）**：
   - 连通域降噪（清除悬浮黑点、暗灰尘）。
   - 半透明边缘（白羽、花瓣、火焰外晕）必须**反预乘 + 亮色提纯**，消灭深灰/暗红脏边。
   - 编码前强制执行 **`4px RGB 边缘扩散`（`dilate_rgb_4px`）**：把 `alpha <= 5` 但距前景 `4px` 内的透明像素 RGB 填为最近前景颜色（保持 `alpha=0`），从根本上解决 VP9 `yuv420p` 色彩次采样把黑底色吸进透明边缘产生的黑边！
   - 火焰/光效等半透明发光元素**禁止放在绿色背景生成**，必须使用 `#000000` 纯黑底生成并走亮色抠像/融合。
5. **真 360° 旋转类专项标准**：
   - **禁止假 360（左右摇摆/摆锤回头/正面背面错位）**：必须单向匀速连续自转一圈，光流水平运动方向一致性 `>= 80%`，侧面呈两条窄波谷（90°/270°），正面与背面（180°）造型配色统一、角速度平稳（`speed_cv <= 0.48`）、摄像机绝对锁死。
6. **网页端交互与调用端兼容**：
   - 小元素详情不展示复杂字幕排版设置，但**支持单独大图预览、切换衬底、调整大小 (`30%~200%`)、左右位置 (`-45%~+45%`)、上下位置 (`-45%~+45%`) 与一键生成 `C-XXXX` 短码及 `ffmpeg_overlay_filter`**。

## 三、动态字幕 (`S-*`) 与覆层 (`O-*`) 全量技术与美学要求

1. **无损原生渲染（严禁 `.ass` 降级）**：
   - 必须通过 `vn_sub_render.mjs`（Node + `@napi-rs/canvas` + `vk-kernel`）或网页原生 Canvas 内核渲染，**禁止将霓虹渐变、笔刷纸张、AE 特效降级编译成 `.ass`**。
2. **越语双层声调与字形铁律**：
   - **仅限 56 款实测越语字体**（如 `Be Vietnam Pro`、`Montserrat`、`Lora`、`TikTok Sans`、`Calistoga` 等）；`D1` `font_keys_json` 字段**必须存 R2 路径数组**（如 `["fonts/BeVietnamPro-Bold.ttf"]`），不能存字体名。
   - **先描边再填充 (`stroke` → `fill`, `lineJoin='round'`)**：绝不内吞 `e/a/o/ê/ộ` 字孔（防 `Amen` 变 `Amon`）。
   - **上下预留 `±32%` 声调安全空间**，保障 `Ấ / Ệ / Ộ / Ứ / Ẫ` 零削顶、零切底点；双行条带底框强制 `"box_connected": false` 且 `line_spacing` 为像素值 **`>= 34`**（严禁写 `1.2` 等小数倍数）。
   - **放大跳跃/磁力动画宽度限制**：使用 `letter_jump` / `word_pop_random` / `magnetic_wave_karaoke` 等放大类动效时，`wrap_width_percent` 须 `<= 80`，防止左右溢出。
3. **超大字高可读 + 神圣零黑边 + 覆层无多余默认标题**：
   - `1080×1920` Canvas 字幕推荐 `fontsize 78 ~ 96`；覆层默认字号中等偏大以适应中老年（不可小到看不清），**常规覆层不强行加多余顶部大标题**（用户或款式设计需要时除外）。
   - 凡天主/耶稣/灵修/圣洁风格，**严禁纯黑/近黑描边或 3D 挤出底色**（用 `#8E1022` 礼仪红、`#B43408` 赤陶、`#1D4ED8` 圣母宝蓝、`#92400E` 暗金等亮暖色）。
   - 预览与试片必须**同时覆盖单行短句与双行长句**（含叠层重音字符），确保单双行都不越界、不粘连。
4. **反“水货同质化”与爆款参考标准**：
   - 严禁靠机械微调几个色号“批量水数量”。新制作样式须基于高赞短视频真实排版规律（大字、强对比底框/描边、逐词卡拉 OK、3D 浮雕/纸张笔刷、8 大 AE 级特效），保持每款独立辨识度。
5. **网页端动效 UI 分层**：
   - 「动画样式」拆分为「基础动效 (`5×2 = 10` 项)」与「AE 特效 (`4×2 = 8` 项，精准对应 `reels-ae-typography.js` 实装引擎)」双页签；覆层与字幕动效列表隔离（仅保留真实支持的动效）；`worker.js` `allowedAnims` 与引擎白名单必须 100% 同步。

## 四、团队协作与安全红线

1. **只读 vs 管理员严格隔离**：`SKILL.md` 公开给剪辑 AI 仅提供查询与无损渲染命令；管理员脚本与密钥不暴露给前端；`AGENTS.md` 与 `pack_manager` 均强制遵守**无用户明确「上新」口令严禁写入云端**。
2. **防并发覆盖**：直连 `/api/v1/publish/*` 须持排他锁；批量入库须更新 `catalog_version` 刷新 CDN 缓存，且本地 `Downloads\AI专用` 与项目 `public/r2/` 保持同 SHA256。
